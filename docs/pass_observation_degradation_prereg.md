# Pass 观测协议性能衰减实验 · 预注册（2026-08-25，跑前冻结）

**问题**：主模型（ch_target_only_gru，F2 正式推理 bundle = val-best ckpt）在 LJ3 真实过站观测协议变体数据集上，性能衰减多少？——回答"方案的任务定义在真实采样协议下是否站得住"。

**资产**：`outputs/f2_formal_5seed/inference_bundle/`（seed42 val-best，test_rmse=0.14521 v2 口径）；`src/sim/pass_observation.py` 生成的 pass 变体（协议参数 = LJ3 审计实测：命中 73.5% / 占位 0.293 / 量化 4 维阶梯）。

## 设计（冻结）

对照臂（同一 ckpt、同一 traj 级 split [0.15/0.20/0.65] seed42、同一 `eval_test` 指标路径、同一 normalizer=**训练统计量 from bundle，禁止重拟合**、TargetSeqDataset L=64 K=8 stride=50 与 F2 逐参数一致）：

| 臂 | 数据 | NaN 处理 | 样本集 |
|---|---|---|---|
| **C0 复现校验** | 原始连续 h5 | 无（全有限） | 与 F2 同构（校验门：\|RMSE−0.14521\|<1e-3，超差停止查因） |
| **C1 pass-ffill（主口径）** | pass 变体 h5 | 每通道序列内前向填充（首段后向）——部署语义：缺测窗 carry-forward 最后已知值 | 与 C0 同样本集（逐样本 paired） |
| C1b per-status 细分（参照） | 同 C1 | — | 窗末点级按 obs_status 分组（normal vs filled）报 RMSE |

指标：失效 RMSE/PHM/MAE + 删失下界违反率（`eval_test` 原口径，v2 归一 RUL 空间）。
主量 **Δ_rmse = RMSE(C1) − RMSE(C0)**，逐样本配对差的 bootstrap 1000 次 95% CI。

## 判读分支（跑前冻结，禁止事后改口径）

| 分支 | 条件（Δ_rmse） | 结论 |
|---|---|---|
| **R1 大衰减** | > 0.05（相对 >34%） | 观测协议是 sim-to-real 的主要域差来源；pass 协议适配升级为 P2 弱监督预注册的前置必做项 |
| **R2 中衰减** | 0.01 < Δ ≤ 0.05 | 可测但非主导；衰减需分解归因（mask 缺测 vs 量化 vs 占位），P2 保持"≥100 过站"数据量前置不变 |
| **R3 小衰减** | ≤ 0.01（相对 ≤7%） | 6h 窗任务粒度对过站协议天然鲁棒——方案任务定义在真实协议下站得住；写入答辩"协议鲁棒性"证据 |

附注判读（描述性，不设确认门）：
- C1b 的 filled 子组 RMSE 与 normal 子组之差 = 填充区误差贡献；
- 删失违反率若 C1 较 C0 上升 = 缺测使模型预测更激进（虚警方向）；
- PHM 同向变化与 RMSE 不一致时如实分别报告。

**探索性声明**：单 ckpt（seed42）n=1，探索性非确认性；Δ 落在阈值边界带（0.008–0.012 / 0.045–0.055）时结论标注边界不确定，比赛阶段不追加 seed。

**纪律**：本实验不改任何 F2/F4 既有指标与 `public_summary.json`；结果作为 LJ3 审计报告（父仓库）的附属证据与 P2 预注册输入；pass 变体生成用 config `observation_adapter` 显式开启，原始数据集只读。

## 结果（2026-08-25 回填，跑前口径未改动）

复现链完整性：C0 校验门通过（rmse 0.14522 vs bundle 0.14521，|Δ|=1e-5，bit-exact 级）；
三次独立运行数字逐次一致（确定性）；C0/C1 同 ckpt 同划分同样本集（294,761 样本 × K=8 窗末）。

| 臂 | RMSE | MAE | PHM | 删失违反率 | 失效窗末点 n |
|---|---:|---:|---:|---:|---:|
| C0 原始连续 | 0.14522 | 0.1051 | 5879.2 | 0.1456 | 607,944 |
| C1 pass-ffill | 0.22058 | 0.1499 | 8495.5 | 0.1371 | 607,944 |
| **Δ（C1−C0）** | **+0.07536** | +0.0448 | +2616 | −0.0085 | — |

Δ_rmse bootstrap 95% CI = **[+0.07486, +0.07590]**（1000 次，60.8 万失效窗末点，全正且极窄）。
C1b：normal 窗末 rmse 0.22014 (n=316,122) vs filled 0.22107 (n=291,822)——差 0.0009。

**判读（预注册分支）**：**R1 大衰减触发**（Δ=+0.0754 > 0.05，相对 +51.9%）——
观测协议是 sim-to-real 的主要域差来源；pass 协议适配升级为 P2 弱监督预注册的
**前置必做项**（sim 侧训练数据应含协议失真，或模型 mask-aware）。

附注判读（描述性，如实记录）：
1. **C1b 机制发现（预注册未预期的模式）**：normal ≈ filled（差 <0.001）——衰减
   **不是**预测点缺测所致，而是**序列级输入分布失真**：L=64 窗内 ~48% 时间步
   （26.5% 无站 + 21.5% 占位）被替换为填充值、正常步被量化，GRU 隐状态被历史
   失真污染，有真实观测的窗末点同样受害。适配方向指向**输入层**（mask-aware
   输入 / 协议对齐训练），"只在有观测时刻预测"无效。
2. 删失违反率 C1 < C0（0.137 vs 0.146）：缺测使模型更**保守**（预测 RUL 偏长），
   虚警（把健康通道判死）方向不恶化——部署安全侧。
3. PHM/MAE 同向恶化（+44.6% / +42.7%），三指标一致，无口径分歧。
4. 探索性声明维持（单 ckpt seed42）；Δ=0.0754 远离边界带（阈 0.05±0.005），
   结论对单 ckpt 不确定不敏感。

**公平性边界**：现役模型训练数据为连续无失真观测，从未见过填充/量化模式——
本数字是"现役模型**直接部署**在真实观测协议下"的诚实口径，不构成对模型本身的
否定；它恰好量化了"不做协议适配的部署代价"，与 R1 结论共同指向：P2 之前须做
协议适配（pass 变体训练或 mask-aware 架构），这也是本实验的工程价值。
